## Deployment Steps

### 1. Check Your Render Dashboard
1. Go to your Render dashboard
2. Check if your services are deploying successfully
3. Look for any failed builds or crashes

### 2. Check Logs
In Render dashboard, click on your service → "Logs" tab to see:
- Build logs (during deployment)
- Runtime logs (after deployment)

### 3. Verify Environment Variables
In your Render service settings, ensure these are set:
```
DATABASE_URL=<from your database>
SECRET_KEY=<auto-generated or your secret>
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
ENVIRONMENT=production
FRONTEND_URL=https://your-frontend-url.onrender.com
```

### 4. Test Database Connection
Visit your backend URL: `https://your-backend-url.onrender.com/health`
This will show:
- API status
- Database connectivity
- Table existence
- RabbitMQ status

### 5. Test Basic Endpoint
Visit: `https://your-backend-url.onrender.com/`
Should return:
```json
{
  "status": "active",
  "message": "Welcome to the Pravaah API!",
  "version": "0.1.0",
  "environment": "production",
  "cors_origins": ["https://your-frontend-url.onrender.com"]
}
```

## Common Issues and Solutions

### Issue: Build Fails
**Check**: Build logs in Render dashboard
**Common causes**:
- Missing dependencies in requirements.txt
- Python version mismatch
- Build timeout

**Solution**: 
```bash
# If build fails, check if all dependencies are in requirements.txt
# Add any missing ones:
pip freeze > requirements.txt
```

### Issue: App Crashes After Deploy
**Check**: Runtime logs in Render dashboard
**Common causes**:
- Database connection issues
- Missing environment variables
- Port binding problems

**Solution**: Check the /health endpoint for specific error details

### Issue: Database Connection Fails
**Symptoms**: Health check shows "database": "disconnected"
**Solutions**:
1. Verify DATABASE_URL in environment variables
2. Check if database service is running
3. Ensure database allows connections from your web service

### Issue: CORS Errors
**Symptoms**: Frontend can't connect to backend
**Solutions**:
1. Verify FRONTEND_URL environment variable
2. Check CORS origins in the root endpoint response
3. Ensure both frontend and backend are deployed

### Issue: Tables Don't Exist
**Symptoms**: Health check shows "users_table": "missing"
**Solutions**:
1. Check build logs to see if `create_tables.py` ran successfully
2. Manually trigger table creation by redeploying

## Frontend Configuration

Ensure your frontend is pointing to the correct backend URL:
```javascript
// In your frontend config
const API_BASE_URL = "https://your-backend-url.onrender.com/api";
```

## Next Steps if Still Having Issues

1. **Check Render Logs**: Most specific error information will be in the logs
2. **Test Health Endpoint**: Visit /health to see detailed status
3. **Verify Database**: Ensure your Render database is running and accessible
4. **Check Environment Variables**: Ensure all required env vars are set
5. **Test Locally**: Ensure your app works locally with similar environment variables

## Render-Specific Tips

1. **Free Tier Limitations**: Services may spin down after inactivity
2. **Build Time**: First deploy may take longer
3. **Database**: Ensure your database service is in the same region
4. **Environment Variables**: Double-check all required vars are set in Render dashboard
